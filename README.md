# فتيل · Fuse Crew

لعبة تعاونية لـ 3 لاعبين بتشتغل في المتصفح (موبايل أو PC) وبتتثبت على الشاشة الرئيسية زي أي تطبيق (PWA)، ومعاها مايك حقيقي جوه اللعبة.

## الأدوار

| الدور | بيشوف القنبلة | الكتيّب | بيسمع | بيتكلم | الإشارات | الأزرار |
|---|---|---|---|---|---|---|
| 🙈 الأعمى (Blind) | ❌ | ❌ | ✅ | ✅ | ❌ | ✅ بيقطع ويضغط |
| 🤐 الأخرس (Mute) | ❌ | ✅ | ✅ | ❌ | ✅ بيبعت | ❌ |
| 🙉 الأطرش (Deaf) | ✅ | ❌ | ❌ | ✅ | ✅ بيستقبل | ❌ |

الدائرة: الأطرش يوصّف القنبلة بصوته (الأخرس والأعمى بيسمعوا) ← الأخرس يدوّر في الكتيّب ويبعت الحل بالإشارات للأطرش ← الأطرش يقول للأعمى بصوته ← الأعمى ينفّذ. كل غلطة بتخصم 15 ثانية و3 غلطات = انفجار (غلطتين في مستويات 8 و10).

## المستويات (10) وأنواع الألغاز (6)

كل مستوى بيتفتح لما تخلّص اللي قبله. التقدم بيتحفظ على الجهاز، وفي الغرفة صاحبها هو اللي بيختار المستوى والباقي بيشوفوه (والمستوى المفتوح للغرفة بيتشارك مع كل اللاعبين).

| المستوى | الألغاز | ملاحظة |
|---|---|---|
| 1 | أسلاك | لغز واحد |
| 2 | أسلاك + رموز | |
| 3 | أسلاك + رموز + كود | |
| 4 | **لمبات** | لغز جديد صعب: جدول الكتيّب بيتغيّر مع كل غلطة |
| 5 | لمبات + **زرار** | |
| 6 | لمبات + زرار + **مورس** | |
| 7 | كل الأنواع | **سباق**: الوقت أقل |
| 8 | كل الأنواع | **الضربة القاضية**: غلطتين بس |
| 9 | كل الأنواع | **ضباب**: القنبلة بتتغطى وتظهر بالتبادل |
| 10 | كل الأنواع + لمبات ومورس تاني | **النهائي**: 8 ألغاز، ضباب، غلطتين |

الألغاز الستة: **أسلاك** (يقطع السلك الصح)، **رموز** (يدوس الرموز بالترتيب)، **كود** (أرقام الكيباد)، **لمبات** (4 وميضات، جدول الكتيّب بيحدد الزرار 1–4 ويتغيّر بعد كل غلطة)، **زرار** (لونه يحدد ضغطة سريعة أو ضغطة طويلة، ولون الشريط يحدد رقم لازم يكون في ثواني التايمر وقت ما يسيب الزرار)، **مورس** (3 مجموعات من 3 وميضات، قصير/طويل، الكتيّب يحوّلها لرقم).

## شكل كل دور

- 🙈 **الأعمى**: شاشة سودا بالكامل زي Bombanana. الأسلاك مجرد خطوط حواف، والأرقام بخط **برايل**. **لمسة قصيرة** = تنفّذ، **ضغطة طويلة** = تكشف الرقم من غير ما تنفّذ (وكده في باقي العلامات). التايمر مخفي عنه عمداً، الأطرش هو اللي يقوله.
- 🙉 **الأطرش**: قنبلة شكلها حقيقي (براغي، لمبات الغلطات، شاشة، شريط تحذير) وأسلاك بألوان واضحة ومميزة وعليها أرقام، واللمبات والمورس بتومّض فعلاً.
- 🤐 **الأخرس**: الكتيّب **كتاب بتقلّب صفحاته**: صفحة فهرس وتبويبات للفصول (المستوى الحالي بس يظهر فيه فصول الألغاز اللي فيه) مع حركة قلب الصفحة. الإشارات اللي يبعتها ممكن يمسح منها (لمسة على الإشارة، أو تراجع، أو مسح الكل) والباقي بيتنبّه (إطار وصوت واهتزاز على صندوق الإشارات).
- لما المايك شغال أونلاين، صندوق الكتابة عند الأعمى والأطرش بيختفي ويظهر "اتكلم بس". بيفضل كبديل لو المايك مش متاح، وفي التدريب على موبايل واحد.

**توزيع الأدوار** (صاحب الغرفة يختار من اللوبي): **عشوائي** (توزيع جديد كل جولة) أو **كل واحد يختار** (كل لاعب يدوس على الدور اللي عايزه، وبيفضل ثابت في الجولات. الدور اللي محدش يختاره بيروح تلقائي لصاحب الغرفة لو اللاعبين أقل من 3). بعد الجولة صاحب الغرفة يقدر يرجّع الكل للغرفة عشان يغيّر الأدوار.

لو غيّرت توزيع الحواس، الجدول الوحيد اللي بيحكم كل حاجة (الواجهة والمايك) هو `CAPS` في `js/engine.js`.

## عالم الـ3D (بديل عن الواجهة)

كل لاعب يختار لنفسه (من اللوبي أو التدريب، أو بزرار صغير أثناء اللعب بيبدّل واجهة ↔ عالم 3D). الاختيار بيتحفظ على جهازه ومش بيأثر على باقي اللاعبين. ده مش مشهد معروض فوق الواجهة: انت **جوا العالم** والحاجات اللي بتتفاعل معاها موجودة فيه.
- **الأعمى**: هو اللي **قاعد قدام القنبلة** (هو اللي بيقطع ويضغط). في الضلمة الكاملة شايف جسم القنبلة ولوحتها المايلة كحواف باهتة، والأسلاك والمربعات والدواير والزرار الكبير والكيباد عليها كأجسام تتلمس + برايل. **لمسة قصيرة** على الحاجة نفسها = تنفّذ (السلك بيتقطع فعلاً)، **ضغطة طويلة** = تكشف الرقم من غير ما تنفّذ، والزرار الكبير بيحس بالضغطة الطويلة بهزّة. الوقت مش بيتعرض ولا بيتبعت للعالم أصلاً.
- **الأطرش**: واقف ورا الأعمى وشايف القنبلة مجسّمة على الترابيزة: لوحة مايلة عليها الموديول الحالي (أسلاك ملونة بأرقام، مفاتيح برموز، شاشات LCD، لمبات بتومّض، الزرار الكبير، لمبة المورس). **الأعمى قاعد قدام القنبلة وإيديه مرتاحة على الترابيزة** (مش واصلة للوحة)، والأخرس واقف ورا القنبلة على مكتبه العالي وظاهر كله فوقها: ماسك كتابه، أو سايبه وبيعمل إشارات بإيديه. الفتيل بيقصر وبيطلّع شرر، ولمبات الغلطات بتنوّر، والشخصيات بتتفاعل مع الغلطات والفوز والخسارة. ممكن يسحب بإصبعه يلف الكاميرا شوية، **وحركة راسه بتظهر على شخصيته للأخرس**.
- **الأخرس**: واقف على مكتب عالي ورا القنبلة وقدامه **كتاب حقيقي مفتوح على صفحتين جنب بعض** (غلاف جلد وسُمك صفحات وسِلك علامة أحمر): صفحة يمين وصفحة شمال زي أي كتاب، **ومفيش سكرول**. الصفحات متقطّعة بالقياس على حجم الشاشة فمفيش حاجة بتتقص (ولو الشاشة صغيرة الخط بيصغر بس لحد ما كل صفحة تتسع). التقليب **بالسحب يمين أو شمال** (في العربي: يمين = لقدّام) والصفحة بتتقلب فعلاً، ورقم كل صفحة مطبوع في طرفها، وأول صفحة فهرس بأرقام الصفحات (اضغط على سطر فيها تروح له). مفيش شريط تحت ولا "صفحة كذا من كذا".
  - **ضغطة طويلة على الكتاب = يسيبه على المنضدة**: الكاميرا بتفتح على الغرفة وهو شايف ظهر القنبلة والأطرش والأعمى والعالم حواليه. يحرّك راسه **بالسحب** (ناحية اللي عايز يبص عليه)، وفي إيديه الاتنين قدامه كل واحدة بـ5 صوابع: **اضغط على صباع يتفرد أو يتطبق** (يعمل أرقام من 0 لـ10)، أو استخدم زراير الإشارات (👍 أيوه، 👎 لأ، ✋ استنى، ✊ قبضة، ☝️ واحد، ✌️ اتنين، ⬇️ نزّل إيديك). **ضغطة طويلة على الكتاب اللي على المنضدة = يمسكه تاني** ويقلّب فيه.
  - الأطرش بيشوف على شخصية الأخرس كل ده: الكتاب في إيديه أو مش في إيديه، إيديه ومعاها الأصابع، حركة راسه، والرقم اللي بيعمله بيطلع جنبه كدايرة صغيرة مساعدة. ولو الأطرش حرّك راسه الأخرس بيشوفها على شخصية الأطرش. الوضع ده بيتبعت في `rooms/<الكود>/pose/<الدور>` (بحد أقصى 8 مرات في الثانية ولما يتغيّر بس) وبيتصفّر مع كل جولة جديدة. الإشارات اللي تحت (الألوان والأرقام والرموز) لسه زي ما هي، دي قناة تانية.
  - القنبلة مش ظاهرة للأخرس وهو بيقرا؛ بتظهر بس من ظهرها لما يسيب الكتاب، وفيها مفيش أي معلومة عن الموديول.
- التايمر وزراير المايك وسماعة الأذن بيفضلوا خارج العالم زي الواجهة. والقواعد واحدة: العالم بيعرض نفس اللعبة بنفس الحالة المشتركة، ومفيهوش أي معلومة زيادة. الأعمى مبيتبعتلوش ألوان ولا حل، والأخرس مبيتبعتلوش الموديول، والأطرش بس اللي بيشوف الألوان.
- التحميل: Three.js (`vendor/three.module.min.js`، حوالي 170 كيلوبايت بعد الضغط) وكود العالم بيتحمّلوا أول مرة بس لما حد يختار 3D، وبعدها بيتخزّنوا. لو الجهاز مفيهوش WebGL أو حصلت مشكلة بيرجع تلقائي للواجهة. كل الرسومات متعملة بالكود (مفيش صور ولا موديلات)، والرموز مرسومة كأشكال فمش محتاجة خط.
- الأعمى اللي بيعتمد على قارئ الشاشة يستخدم **الواجهة** (عناصرها بتتقرا)، لأن لمس الـ3D بصري.
- الكود: `js/scene.js` (اللي بيتبعت للعالم + منطق الحالة المزاجية)، `js/world3d.js` (الغرفة والقنبلة والشخصيات والكاميرا واللمس)، `js/world-book.js` (الكتاب الحقيقي) و`js/bookspread.js` (صفحتين جنب بعض وتقطيع النص وقلب الصفحات) و`js/world-hands.js` (الإيد بخمس صوابع والإشارات)، `js/world-modules.js` (الألغاز الستة كأجسام: شكل الأطرش وشكل الأعمى)، `js/world-art.js` (الخامات المرسومة بالكود). كله بيتحسب من حالة اللعبة المشتركة، والحاجة الإضافية الوحيدة اللي بتتكتب في Firebase هي وضع الأخرس والأطرش (إيدين وراس) في `rooms/<الكود>/pose` وقواعد `rooms` الحالية بتسمح بيها من غير تعديل.

## الحسابات والأصدقاء

- **ضيف**: اكتب اسمك والعب. التقدم بيتحفظ على الجهاز ده بس.
- **حساب** (اسم + كود، 6 حروف/أرقام على الأقل): التقدم بيتحفظ في الحساب نفسه فيمشي معاك على أي موبايل ويفضل محفوظ مع كل تحديث للعبة. الاسم ثابت ومش بيتكرر (مفيش حرف كبير/صغير ولا مسافات تفرق).
- **البصمة** (اختيارية): من شاشة الحساب. بتقفل الحساب على الجهاز ده بالبصمة أو قفل الشاشة. لو دخلت من جهاز تاني لازم الاسم والكود.
- **الأصدقاء**: ضيف صديق باسمه، هو بيقبل من إشعار، وبعدها من أي غرفة تقدر تدعوه، فيظهرله إشعار فوق الشاشة بكود الغرفة وزرار "انضم". الإشعارات بتظهر والتطبيق مفتوح (إشعارات الخلفية محتاجة سيرفر مدفوع).
- التقدم بيتكتب في الغرف بس. التدريب كل مستوياته مفتوحة ومش بيغيّر التقدم.
- تقنياً: الاسم بيتحوّل لإيميل داخلي (`<hex>@players.fuse-crew.app`) والكود هو الباسورد في Firebase Authentication، فلازم تفعّل **Email/Password** (Authentication ← Sign-in method). قواعد `users` و`usernames` و`friends` و`friendReqs` و`invites` في `database.rules.json` وبتتنشر أوتوماتيك من GitHub Actions.
- **متغيّرش** اسم `fuse-progress` في localStorage ولا مسارات `users/` في قاعدة البيانات في أي تحديث، عشان تقدم اللاعبين يفضل محفوظ.

## المايك والسماعة جوه اللعبة

- أول ما تدخل غرفة، المايك والسماعة بيشتغلوا لوحدهم (المتصفح هيطلب إذن المايك مرة).
- **مؤشر المستوى:** شريط رفيع على زرار المايك بيتحرك مع صوتك (لو اتحرك وإنت بتتكلم يبقى المايك شغال)، وشريط على زرار السماعة بيتحرك لما حد يتكلم ويوصلك صوته، وفي اللوبي شريط صغير جنب كل لاعب. المستوى بيتقاس بـ Web Audio في `js/voice.js` (`levels()`) وبيحترم قواعد الحواس: مايك الأخرس المقفول وسماعة الأطرش المقفولة بتقرا صفر ومفيش شريط، فالأطرش مايعرفش إن حد بيتكلم.
- أيقونة **المايك** وأيقونة **السماعة**: ضغطة تقفل وضغطة تفتح. أيقونة النغمة ♪ في أعلى الشاشة تخص **مؤثرات اللعبة** بس (مش صوت اللاعبين).
- في اللوبي وفي عدّاد الـ 5 ثواني ("استعد") **كلكم بتتكلموا وتسمعوا بعض**، وفي اللوبي سطر بيقولك لو الكل متصل بالصوت ولا حد لسه ما فتحش المايك.
- من لحظة ما الوقت يشتغل اللعبة بتقفل **مايك الأخرس** و**سماعة الأطرش** إجباري (الأيقونة بتظهر عليها قفل ومبتفتحش). لما الجولة تخلص بيتفتحوا تاني.
- الصوت بيروح من جهاز لجهاز مباشرة (WebRTC)، وFirebase بيشيل المصافحة بس. بيحتاج HTTPS (GitHub Pages و Firebase Hosting بيدّوه تلقائي).
- لو لاعبين مش سامعين بعض (غالباً على داتا الموبايل أو واي فاي شركات) ضيف سيرفر TURN في `rtc-config.js`. الشات النصي موجود كبديل.

## زر الرجوع والـ refresh

- زر الرجوع بتاع الموبايل/المتصفح بيتحرك جوه اللعبة بس: في الرئيسية بيسأل "تخرج من اللعبة؟"، وفي الغرفة أو الجولة بيحذّرك إنك هتخسر الغرفة والتقدم، ومبيخرجكش من غير تأكيد.
- الـ refresh (أو سحب الشاشة لتحت) مبيأثرش: اللعبة بترجّعك لنفس الغرفة ونفس الجولة ونفس الدور (حتى التدريب على موبايل واحد). سحب الشاشة لتحت متقفل أصلاً.
- لو قفلت التطبيق وفتحته تاني وإنت لسه في غرفة، بيرجّعك ليها.

## الشكل

تصميم هادي للعين بوضعين: **داكن** و**فاتح** (أيقونة الشمس/القمر في أعلى كل شاشة). الاختيار بيتحفظ، وأول مرة بياخد وضع الجهاز. الخط Cairo (مرخّص OFL) موجود في `fonts/` عشان يشتغل أوفلاين.

## 1) تجربة سريعة على جهازك (من غير Firebase)

```bash
python3 -m http.server 8000
```

افتح `http://localhost:8000` في 3 تبويبات من نفس المتصفح. ده "وضع تجريبي" بيستخدم localStorage. زرار "تدريب على موبايل واحد" بيشتغل لوحده بالأدوار التلاتة وبدون إنترنت (من غير صوت) وبيتكمل بعد الـ refresh.

## 2) Firebase خطوة بخطوة

1. افتح console.firebase.google.com ← **Add project** ← اسم (مثلاً `fuse-crew`) ← Analytics اختياري ← **Create project**.
2. **Build ← Authentication ← Get started ← Sign-in method ← Anonymous ← Enable ← Save**.
3. **Build ← Realtime Database ← Create Database** ← اختار أقرب منطقة (مثلاً `europe-west1`) ← **Start in locked mode** ← Enable. انسخ رابط قاعدة البيانات اللي فوق (شكله `https://...firebasedatabase.app` أو `...firebaseio.com`).
4. تبويب **Rules** ← امسح اللي موجود والصق محتوى `database.rules.json` ← **Publish**.
5. **Project settings (علامة الترس) ← General ← Your apps ← أيقونة `</>` (Web)** ← اسم ← **Register app** (من غير Hosting) ← انسخ `firebaseConfig`.
6. افتح `firebase-config.js` وحط القيم (`apiKey`, `authDomain`, `databaseURL`, `projectId`, `appId`). لو `databaseURL` مش في الـ snippet خده من الخطوة 3. الـ config ده مش سري، الحماية في الـ Rules.
7. **Authentication ← Sign-in method ← Email/Password ← Enable ← Save** (للحسابات. الـ Anonymous يفضل شغال للضيوف).
8. **Authentication ← Settings ← Authorized domains ← Add domain**: ضيف `USERNAME.github.io` (أو دومين Firebase Hosting). من غير الخطوة دي الدخول الخفي بيفشل.

## 3) GitHub خطوة بخطوة

1. github.com ← **New repository** ← اسم `fuse-crew` ← **Public** (GitHub Pages في الحساب المجاني محتاج repo عام) ← Create.
2. ارفع الملفات (كل المحتوى جوه فولدر `fuse-crew`، بما فيه `js/` و`icons/`):
   - من الموقع: **uploading an existing file** واسحب الملفات والفولدرات، ثم **Commit changes**.
   - أو من الترمنال:
     ```bash
     cd fuse-crew
     git init && git add . && git commit -m "Fuse Crew"
     git branch -M main
     git remote add origin https://github.com/USERNAME/fuse-crew.git
     git push -u origin main
     ```
3. **Settings ← Pages ← Source: Deploy from a branch ← Branch: `main` / `(root)` ← Save**. بعد دقيقة أو اتنين الرابط يظهر: `https://USERNAME.github.io/fuse-crew/`.
4. ضيف `USERNAME.github.io` في Firebase Authorized domains (خطوة 7 فوق).
5. افتح الرابط على موبايلين وجرّب.

**بديل: Firebase Hosting** (`firebase.json` جاهز): `npm i -g firebase-tools` ← `firebase login` ← `firebase init hosting` (اختار المجلد الحالي كـ public ومتكتبش فوق `index.html`) ← `firebase deploy`.

## 4) التثبيت على الموبايل

- **Android (Chrome):** زرار "ثبّت اللعبة" في الصفحة الرئيسية أو القائمة ⋮ ← Install app.
- **iPhone (Safari):** زرار المشاركة ← Add to Home Screen.

الاسم: **فتيل**، واللوجو في `icons/`.

## 5) بعد أي تعديل

غيّر `CACHE = 'fuse-v13'` في `sw.js` إلى `fuse-v14` وهكذا، عشان التليفونات تاخد النسخة الجديدة.

## ربط Claude بـ GitHub و Firebase

- **GitHub:** من claude.ai ← Settings ← Connectors ← GitHub ← Connect. بعدها في نفس المحادثة Claude يقدر يربط الـ repo بالجلسة (ويرفع عليه). لو الـ repo خاص ممكن تحتاج تدي Claude GitHub App صلاحية عليه.
- **Firebase:** مفيش connector جاهز لـ Firebase ظاهر. اعمل الخطوات اليدوية فوق، وابعت الـ `firebaseConfig` في المحادثة (مش سري) وClaude يحطه في `firebase-config.js`. متبعتش أبداً مفاتيح service account ولا توكن `firebase login`.
